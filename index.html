留痕 Agent 是运行在你 Windows 电脑上的桌面自动化智能体：操作文件、执行命令、截屏、控浏览器。它做的每一件事，都以事件流的形式追加写入审计日志，随时批准、拒绝、取消。

你亲眼核对它做过的每一件事，而不是相信它。

三档审批门：该自动的自动，该问的必问。

每个动作都按风险分级，策略分宽松、标准（默认）、严格三档，随时切换。危险路径不靠策略：直接拒绝。

safe 自动执行
读文件、截屏、打开网页这类只读操作直接执行，不打断你；事件照常落进时间线。 读文件截屏浏览网页
confirm 暂停待批
写文件、执行命令之前，把内容原文摊开等你批准；不批准，一个字节都不会动。任务栏图标会闪烁提醒，刚才标签页标题的闪烁就是同一件事。 写文件移动文件PowerShell
dangerous 直接拒绝
删除文件、格式化、改注册表这类高危命令永远需要确认；而系统目录、盘符根目录、用户主目录，在任何策略下都拒绝执行，拒绝本身也写入审计。 删除格式化注册表系统目录

需要你确认的操作，还可以推送到同一局域网的手机，人不在电脑前也批得了。地址自带访问令牌，请勿外传。

发生过的事，查得到，带得走。

  • 实时滚动：所有事件按发生顺序追加，按类型过滤、关键词搜索。
  • 逐条可查：点击任意事件展开 JSON 详情，截图直接内嵌预览。
  • 一键导出：自包含的 HTML 审计报告，截图以 base64 内嵌，单个文件即可归档、转发。

一个智能体，二十四件工具。

对话驱动
用一句话下达任务。文件读写与搜索、PowerShell 命令、屏幕截图、浏览器控制（Edge / Chrome CDP）、窗口枚举，以及原生键鼠（鼠标移动 / 点击 / 滚动、组合按键、文字键入），直接作用于真实桌面，共 24 个工具。
模型双通道
接任何 OpenAI 兼容的云端服务（智谱 GLM、DeepSeek、Kimi、通义、OpenAI 或自定义端点），也能一键切到本地 Ollama。截图自动回传视觉模型，思考型模型的思考过程实时可见。
内核可靠
任务执行中发来的消息自动排队，当前任务结束后依次发送；取消留下的未完成调用自动修复，对话记录永远可用；限流、服务端故障、网络抖动自动退避重试；上下文超预算自动压缩；随时中止。
技能沉淀
完成过的任务一键存成技能，随时编辑、一键重跑，上面的演示会话里就可以试一次。
定时执行
技能可以设定时计划：每天定时、按间隔重复或只跑一次。开启「关闭到托盘」后应用常驻后台，到点自动在全新会话里执行，完成发系统通知。
远程审批
高风险操作可以推送到同一局域网的手机 / 平板：打开令牌门禁的审批页，看清参数原文，一键批准或拒绝，决定同样写入审计。

# 克隆仓库，安装依赖，启动开发模式
git clone https://github.com/FANG050829/trace-agent.git
cd trace-agent
npm install
npm run dev
  1. 启动后，左下角打开「设置」。
  2. 添加服务商（智谱 GLM、DeepSeek、Kimi、通义、OpenAI 或本地 Ollama），填入 API Key，测试连接后选择模型。
  3. 保存，回到对话页开聊。右侧审计时间线从第一句话开始留痕。

本地模型：安装并启动 Ollama（ollama pull qwen3:8b），在设置页选择「使用本地 Ollama」。
不想装环境？运行 npm run dist 打出 Windows 安装包（NSIS），装完即用。
数据位置：全部数据写入项目目录 .data\，不写系统盘；打包版默认在程序旁，可用 data-dir.txt 标记文件或环境变量改到任意位置。

边界，说在前面。

真实的电脑
它运行在你的真实系统上，文件操作有完整审计；但请自行备份重要数据。
隔离的浏览器
浏览器自动化使用独立用户数据目录，不带你日常浏览器的登录态，也不会碰你正开着的浏览器。
命令的硬边界
默认 60 秒超时、输出截断 64KB；高危命令在任何策略下都要确认；文件移动、重命名拒绝覆盖已存在的目标。
实验性即实验
「微信发消息」依赖窗口焦点与模拟按键，失败立即停止并汇报，不会硬试到底。
真实的键鼠
原生键鼠工具直接操作你正在使用的桌面：每一次移动、点击、按键都先经你确认；agent 被要求先截图看清、走一小步、再验证。
令牌勿外传
局域网审批地址自带访问令牌，仅限可信网络使用；没有令牌的访问一律拒绝。
