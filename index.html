快速开始 / quick-start

        
五分钟，跑在你自己的电脑上。

      

      

        

          

            
            Windows PowerShell
            
          

          
# 克隆仓库，安装依赖，启动开发模式
git clone https://github.com/FANG050829/trace-agent.git
cd trace-agent
npm install
npm run dev

# 不想装环境？打出 Windows 安装包（NSIS），装完即用
npm run dist

# 本地模型：安装并启动 Ollama 后，设置页选「使用本地 Ollama」
ollama pull qwen3:8b

    2.

    3. 
            
  3. 保存，回到对话页开聊。右侧审计时间线从第一句话开始留痕。

边界 / limits

        
边界，说在前面。

        
它跑在真实系统上。这些地方它绝不碰。

      


      
      

        

          
绝不写入

          

            系统目录盘符根目录
            用户主目录注册表
          

        

        

          
命令硬限制

          

            60 秒超时输出截断 64KB
            拒绝覆盖已有目标高危命令必确认
          

        

        

          
隔离运行

          

            独立浏览器用户目录不接管日常登录态
            不碰你开着的浏览器
          

        

        

          
对外暴露

          

            局域网审批自带令牌无令牌访问一律拒绝
            仅限可信网络
          

        

      

      
原生键鼠每一次移动、点击、按键都先经你确认；「微信发消息」这类依赖窗口焦点的操作失败即停，不会硬试到底。请自行备份重要数据。
